Batch review: nothing reaches a student until the teacher approves that week's set.
How generation works in this prototype: text is produced by a local template engine (no external API — works offline, free, instant). Audio uses your browser's built-in Text-to-Speech and Speech-to-Text (also free, no server). Images are original hand-authored scenes rendered as SVG (no external image service). Every module here is written behind a swappable interface, so upgrading to a locally-hosted generative model later (text, voice, or image) changes the engine, not the app around it.
