How this app makes the exercises

Text comes from a local template engine — no external service, so it works offline, free and instantly. Audio uses your browser's own Text-to-Speech and Speech-to-Text. Images are hand-authored SVG scenes. Each module sits behind a swappable interface, so moving to a locally-hosted model later changes the engine, not the app around it.

How the daily batch works

Generate and share a fresh set every class day — the weekly theme keeps you on the 12-week plan, but each day gets its own link and QR code.

🎯 Assign to one student (optional)

When to assign to one student

Pick a task type and theme just for this student — independent of what's selected above, so you're free to give someone a different focus than the rest of the class right now. Uses only the first name you type here; nothing is stored beyond this session.

Sign in to open your class

This panel holds your class list and each student's practice history, so it opens once you sign in. Students never sign in — they tap their name from a link you share.
